# Package index

## Visualization Functions

Main visualization functions for multi-omics data analysis.

- [`matrixPlot()`](https://byronsyun.github.io/vizOmics/reference/matrixPlot.md)
  : Score matrix plot
- [`plotSankey()`](https://byronsyun.github.io/vizOmics/reference/plotSankey.md)
  : Plot Sankey Diagram for Classification Results
- [`plotCircos()`](https://byronsyun.github.io/vizOmics/reference/plotCircos.md)
  : Create circos plot for multimodal correlations
- [`plotCorrelation()`](https://byronsyun.github.io/vizOmics/reference/plotCorrelation.md)
  : Plot Correlation Matrix as Heatmap
- [`plotCorrelationAnnotated()`](https://byronsyun.github.io/vizOmics/reference/plotCorrelationAnnotated.md)
  : Plot Correlation Matrix with Annotations
- [`plotGroups()`](https://byronsyun.github.io/vizOmics/reference/plotGroups.md)
  [`.extract_phispace_data()`](https://byronsyun.github.io/vizOmics/reference/plotGroups.md)
  : Plot Group Differences in Numeric Features
- [`plotGroupsMultiMetric()`](https://byronsyun.github.io/vizOmics/reference/plotGroupsMultiMetric.md)
  : Plot Groups with Multiple Metrics
- [`plotLoadings()`](https://byronsyun.github.io/vizOmics/reference/plotLoadings.md)
  : Plot loadings of dimension reduction as bar plot.

## Utility Functions

Helper functions for data processing.

- [`align_clusters()`](https://byronsyun.github.io/vizOmics/reference/align_clusters.md)
  : Align clustering results to a reference.
