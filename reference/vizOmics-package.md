# vizOmics: Visualization Tools for Multi-Omics Data Analysis

A collection of visualization and utility functions for multi-omics data
analysis. Includes tools for clustering alignment, score matrix
visualization with intelligent color detection, and interactive Sankey
diagrams for comparing classification results. Functions originally
developed for the PhiSpace package.
